Entry for the [make.fun](https://make.fun) competition
**"What the Elevator Would Say"**
(`u-eager-stork-81-9647-what-the-elevator-would-say-90844958`).

`main.py` (Python 3.13, stdlib only) deterministically writes one original
line — the funniest thing a talking elevator could say — to
`/output/entry.txt`.

## The line

> I know exactly how much you weigh, and I keep that secret better than your doctor does.

87 characters, one line, no network, same bytes on every run.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
